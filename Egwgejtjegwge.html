10. Linux Systemd Service

                
[Unit]
Description=Minecraft PaperMC Server
After=network.target

[Service]
WorkingDirectory=/home/minecraft/server
ExecStart=/usr/bin/java -Xms8G -Xmx8G -XX:+UseG1GC -jar paper.jar --nogui
Restart=always

[Install]
WantedBy=multi-user.target

15. Khắc Phục Lỗi Crash Common

                
1. OutOfMemoryError: Hết RAM -> Tăng -Xmx trong script.
2. Port 25565 in use: Trùng port -> Đổi port trong server.properties.
3. UnsupportedClassVersionError: Sai bản Java JDK.
